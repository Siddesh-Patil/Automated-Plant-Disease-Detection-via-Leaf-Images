🌿 Research Project

About This Project

Automated Plant Disease Detection via Leaf Images leverages deep learning to help identify crop diseases early — enabling faster intervention and healthier yields.

📌 Project Overview

🎯

Objective

Build an AI-powered system capable of detecting diseases in crop leaves from images using convolutional neural networks (CNNs).

🌾

Supported Crops

The model covers 5 major crops: Banana, Corn, Cotton, Rice, and Wheat — with 28+ disease classes total.

🌍

Multilingual

Interface available in English, Hindi, and Marathi to reach a wider farming community.

💊

Treatment Advice

Beyond detection, the system provides tailored fungicide and fertilizer recommendations for each disease.

🔄 How It Works — System Flowchart

📷
Input
User uploads a leaf image & selects crop type
→
🖼️
Preprocessing
Image resized to 224×224, normalized for CNN input
→
🧠
CNN Model
ResNet-based PyTorch model runs inference on the image
→
📋
Results
Disease label, confidence score & treatment returned
1
Image Upload

User selects crop category (Banana / Corn / Cotton / Rice / Wheat) and uploads a JPG, PNG, or BMP leaf photo via drag-and-drop or file picker.

2
Server-Side Preprocessing

Flask backend saves the image and passes it through torchvision transforms: resize → center crop → tensor normalization using ImageNet mean/std.

3
Deep Learning Inference

A crop-specific ResNet model (trained and saved as model.pt) performs forward pass prediction and returns the class probability distribution via softmax.

4
Post-Processing & Display

Top predicted class (disease label) and confidence score are extracted. Treatment guide and fertilizer recommendations are looked up from a curated knowledge base and rendered on-screen.
